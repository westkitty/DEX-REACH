# Non-trigger Cases

Do not trigger for:

1. `Fix GrokBot.`
2. `Why is macOS slow?` when the user wants generic advice rather than DEX//REACH maintenance.
3. `Delete my Downloads folder.`
4. `Clean up this Git repository.`
5. `Upgrade Homebrew packages.`
6. `Archive these files to Google Drive.` when no Mac-maintenance/removal workflow is involved.
7. `Check the DEX//REACH repository for bugs.`
8. `SSH into Big Mac and run this benchmark.`

Adjacent operations should route to their own workflow rather than borrowing this Skill's maintenance authority.
