# Failure Contract

Return a bounded status instead of escalating.

## BLOCKED

Use when target identity, Big Mac acknowledgement, kernel/policy integrity, manifest/menu binding, exact path metadata, live-use checks, configuration-reference checks, or required archive verification fails.

For an `available-for-work` absolute goal, also block if no fresh DexCleaner sample exists.

For Drive preservation:

- a copy timeout is not proof of failure or success;
- reconcile the exact remote destination after timeout;
- matching remote MD5 -> may become verified;
- mismatched/unverifiable remote object -> block;
- absent remote object -> keep local and report archive failure.

## PARTIAL

Use when independent candidates split between success and safe skip/failure, or a bounded reconnaissance scan reaches a limit. Preserve original menu provenance for each durable result.

## INSPECTION ONLY

Use when no mutation was authorized or no eligible candidate exists. Still produce the optional menu when appropriate.

## CLEAN

Use only after post-mutation verification.

## Never escalate

Do not respond to permission errors, stale menus, active owners, failed lsof/config checks, rclone failures, path drift, or unexpected output by using sudo, broader paths, direct deletion, another executor, stronger cleanup mode, guessed menu numbers, or unverified removal.
